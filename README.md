## The Functions of the Script
Running the main.nf script takes the inputs from the data folder and calls 3 processes (fastqc, trimmomatic, bwa-mem2) to analyse the raw sequence read quality (quality control step), remove the raw read adaptors, and low-quality bases (preprocessing step), analyse the preprocessed sequence read quality (quality control step), and align the preprocessed files to a reference genome (alignment step).

#### FastQC:
FastQC processes fastq files as inputs. These can be either single-end reads or paired-end reads (in tuple format). FastQC analyses the quality of the input reads by inspecting the quality of each read, the quality of each base, and the presence of adapters. It outputs a detailed report for each input, saved as a compressed file (fastqc.zip) or viewable via browser (fastqc.html).

#### Trimmomatic:
The trimmomatic takes both raw fastq files and adapter sequences as inputs. Similar to FastQC, the raw fastq files can be either single-end reads or paired-end reads (in tuple format). Trimmomatic performs preprocessing steps on the raw fastq files by removing the adapters, removing regions of the sequences below a quality threshold, trimming the reads to a specified length, and dropping reads below the specified length. It outputs trimmed and filtered fastq files. 
For single-end raw fastq files inputted, a single output file is generated with the processed reads.
For paired-end raw fastq files inputted, four output files are generated with the processed reads. Two files contain the paired outputs, where both the forward and reverse reads were detected post-processing (.trimmed.fq.gz). Two other files contain the unpaired outputs, where either the forward or reverse reads, but not both, were detected post-processing (.discarded.fq.gz). The paired outputs are kept for further processing/alignment, and the unpaired outputs are discarded due to their low-quality.
